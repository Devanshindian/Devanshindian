### Things I've built

**[backlink-gets-automated](https://github.com/Devanshindian/backlink-gets-automated)**
A machine that earns backlinks for a company. It catalogues the whole site, finds ideas worth
writing about, researches one properly, and writes it. Every fact carries a quote and a live
URL, and a separate step opens that URL to check the number is really there.

**[jctrans-directory-engine](https://github.com/Devanshindian/jctrans-directory-engine)**
Pulls the JCtrans freight-forwarder directory for a country and route, and exports the
companies and their contacts to a workbook. Resumable, so a crash costs you nothing.

**[initial-portfolio-screener](https://github.com/Devanshindian/initial-portfolio-screener)**
Turns a venture debt fund's screening checklist into something an AI runs the same way every
time. Reads the financials, computes every ratio, writes the memo.

### How I build

- **Code counts, AI judges.** If it can be counted, a script counts it. If two sensible people
  could disagree, the model decides.
- **Nothing is invented.** Every claim traces to a source someone can open.
- **Every step writes a file.** So a crash resumes, and any number can be walked back to the
  step that produced it.
